# NotePro - সহজ নোটপ্যাড

একটি সুন্দর এবং সহজ নোটপ্যাড অ্যাপ্লিকেশন Android এর জন্য।

## বৈশিষ্ট্য
- ✨ আধুনিক Material 3 ডিজাইন
- 📝 সহজ এবং দ্রুত নোট লেখা
- 🎨 সুন্দর UI
- 🚀 Jetpack Compose দিয়ে তৈরি

## বিল্ড করা

```bash
./gradlew assembleDebug
```

## APK ডাউনলোড

GitHub Actions থেকে APK ফাইল ডাউনলোড করুন।

## GitHub Actions

প্রতিটি push এর সময় স্বয়ংক্রিয়ভাবে APK বিল্ড হয়।
